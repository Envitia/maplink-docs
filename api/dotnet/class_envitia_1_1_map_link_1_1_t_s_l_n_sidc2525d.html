Detailed Description

Represents a 20-digit MIL-STD-2525D Symbol Identification Code (SIDC).

This class parses a SIDC into individual fields that describe a military symbol's context, identity, symbol set, status, indicators, entity and modifiers. These fields can also be set directly to construct or modify a code, and ToString converts the current field values back to a SIDC.

Use IsValid to check the supported field values and IsCivilian to determine whether the fields identify a civilian symbol. An instance can be passed to TSLNMilitarySymbologyGenerator::getSymbol to request the corresponding symbol; this class describes the symbol but does not create or draw it.

Field positions are numbered from 1 in the SIDC string.

Construct a SIDC with default field values.

Version is 10, Context is Reality, StandardIdentity is Pending, SymbolSet is Unknown, Status is Present and HqTfDummy is None. All remaining fields are zero.

virtual System::String ^ Envitia::MapLink::TSLNSidc2525d::ToString ( )

Convert the current field values to a SIDC string.

Numeric fields are padded with leading zeroes to their SIDC field widths. This method does not validate the fields; check IsValid before using the result as a MIL-STD-2525D code.

Returns
The SIDC string, containing 20 digits when the field values are valid.
