Envitia::MapLink::TSLNMilitarySymbologyGenerator Class Reference
MapLink Pro Developer Toolkit » MapLink.Net

Detailed Description

Creates MIL-STD-2525D military symbols from Symbol Identification Codes (SIDCs).

Load the SVG symbol components with loadSymbols before requesting symbols. The returned symbol is owned by the caller and is released when it is disposed.

◆ getSymbol() [2/2]

TSLNSymbol ^ Envitia::MapLink::TSLNMilitarySymbologyGenerator::getSymbol ( TSLNSidc2525d^ sidc,
TSLNSidc2525dSymbolSet cyberspace,
TSLNMilitarySymbologyOptions^ options )

Generate a military symbol from a parsed SIDC.

For cyberspace SIDCs, cyberspace specifies the dimension used to select the symbol frame. For other symbol sets it is not used. If options is null, the default appearance options are used.

Parameters
sidcThe parsed MIL-STD-2525D Symbol Identification Code.
cyberspaceThe dimension symbol set used for cyberspace SIDCs, such as Air, Space, LandUnit, SeaSurface or SeaSubsurface.
optionsThe symbol appearance options, or null to use defaults.
Returns
The generated symbol, or null if sidc is null or invalid, the required components are unavailable, or symbol generation fails. The returned symbol is owned by the caller and should be disposed when no longer needed.
