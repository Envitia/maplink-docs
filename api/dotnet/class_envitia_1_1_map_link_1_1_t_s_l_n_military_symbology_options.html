Envitia::MapLink::TSLNMilitarySymbologyOptions Class Reference
MapLink Pro Developer Toolkit » MapLink.Net

Detailed Description

Provides options for the display of military symbols.

This class controls the appearance of symbols created by TSLNMilitarySymbologyGenerator. It specifies the symbol scale, whether civilian symbols use a magenta fill or their standard identity colour, and whether the operational condition amplifier is displayed as a colour bar or a solidus.

Create an instance, set the required properties and pass it to TSLNMilitarySymbologyGenerator::getSymbol when requesting a symbol. The options configure symbol generation; this class does not create or draw symbols itself.
