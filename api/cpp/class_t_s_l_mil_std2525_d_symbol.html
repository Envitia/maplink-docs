Detailed Description

TSLMilStd2525DSymbol

A configuration class for building MIL-STD-2525D (20-character) SIDC codes using named enumerations. Set the desired fields, then call toSidc() to produce the 20-character code string.

Example usage:

TSLMilStd2525DSymbol sym; sym.setStandardIdentity(TSLMilStd2525DSymbol::SI_Friend); sym.setSymbolSet(TSLMilStd2525DSymbol::SS_LandUnit); sym.setStatus(TSLMilStd2525DSymbol::STS_Present); sym.setEntity(1); sym.setEntityType(1);

char sidc[21]; sym.toSidc(sidc); // sidc == "10030100000101000000"
