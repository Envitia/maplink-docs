TSLSidc2525d Struct Reference

Detailed Description

The parsed representation of a 20-character MIL-STD-2525D Symbol Identification Code (SIDC) Fields are freely modifiable to permit building of a symbol programmatically.

See also
MIL-STD 2525D for field details.

◆ parse()

bool TSLSidc2525d::parse ( std::string_view code)

Parse from a 20-character SIDC code. Parses a 20-character MIL-STD-2525D Symbol Identification Code (SIDC) into its constituent fields.

Field layout (positions 1-based): 1-2 : Version (e.g. "10" for 2525D) 3-4 : Standard Identity (00-06) 5-6 : Symbol Set (two digits) 7 : Status (0=Present, 1=Planned/Anticipated) 8 : HQ/Task Force/Dummy indicator 9-10 : Amplifier 11-12 : Entity 13-14 : Entity Type 15-16 : Entity Subtype 17-18 : First Modifier 19-20 : Second Modifier

Note
Failure to parse will modify the object and leave a mixture of old and new values.
Parameters
[in]codeSIDC to parse, consisting of exactly 20 ASCII decimal digits.
