TSLMilitarySymbologyGenerator Class Reference
MapLink Pro Developer Toolkit » Core API

Detailed Description

The TSLMilitarySymbologyGenerator class creates MIL-STD-2525D military symbols as TSLEntitySet objects that can be rendered on a MapLink drawing surface.

SVG symbol component files must be loaded from a directory before symbols can be created.

Example usage:

TSLMilitarySymbologyGenerator gen; if (gen.loadSymbols("path/to/svgs")) { TSLSymbol* es = gen.getSymbol(TSLSidc2525d{"10031000001101000000"}, TSLSidc2525d::SymbolSet::Space); // ... draw via TSLRenderingInterface::drawEntity(es) ... es->destroy(); }

TSLSymbol * TSLMilitarySymbologyGenerator::getSymbol ( TSLSidc2525d const & sidc,
TSLSidc2525d::SymbolSet cyberspace_dimension,
TSLMilitarySymbologyOptions options = {} )

Create a TSLSymbol from a parsed SIDC.

Symbol data is cached in the TSLDrawngSurfaceBase symbol cache. Repeated calls with the same arguments will re-use data from the symbol cache.

Parameters
sidc[in]MIL-STD-2525D Symbol Identification Code.
cyberspace_dimension[in]When rendering a cyberspace symbol, use this frame. Prefer TSLSidc2525d::SymbolSet::Unknown for non-cyberspace codes.
options[in]Raster rendering options.
Returns
A TSLSymbol representing the composed symbol, or NULL if the SIDC is invalid or required symbol components were not found. The caller owns the returned entity set and must call destroy() on it.
