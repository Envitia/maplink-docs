## 11.3

[**New in 11.3! Cross-platform Drawing Surface**](../../features/cross-platform-surface)    
MapLink Pro 11.3 introduces a major step forward in the platform’s evolution towards  supporting cross-platform, code-once-deploy-anywhere geospatial applications. This version of MapLink Pro delivers a new **Skia‑based 2D rendering foundation** and modern **.NET UI integrations for WPF and Avalonia**.

> **IMPORTANT**: MapLink Pro 11.3 updates our .NET libraries to .NET 10 and MSVC 2026 (v145).

## Known Issues
- Skia line rendering goes wrong on zoom on linux.
- Skia raster handling not implemented on linux.
- The Editor .NET SDK is not yet supported in 11.3. The Editor .NET SDK currently uses Windows GDI rendering that is not compatible with .NET 10.
